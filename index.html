Static gallery generator v1.0 · MIT

SakuraView

把 Galgame 的 CG 从各家引擎的打包文件里解出来，生成零依赖、双击即看的静态图库。 没有服务器，没有构建流程，只有一个文件夹。

file:// 直接可用 单库 十万张 示例素材全部合成
进入示例库 → GitHub 源码

界面

截图来自自带示例库
02

能做什么

解包 → 整理 → 建站
01

解包

Ren'Py 的 .rpa、QLIE 的 FilePackVer3.0/3.1、Godot 的 .pck 直接解，Unity 走 AssetStudio 导出纹理。

02

整理

按目录名归成「事件CG / 立绘 / 头像 / 动画」；一个都认不出时按「目录即分类」兜底，不会一张图都收不到。

03

看图

灯箱进真全屏，滚轮与双指缩放、拖拽平移、R 旋转。每张图的缩放按图记忆，退出后自动滚回那一张。

04

收藏与备注

收藏倒序、行内备注支持 **粗体** 与 #标签，标签并入侧栏过滤，一键导出导入 JSON 备份。

05

视频

自制播放器：倍速、循环、连播、音量滑块、画中画、播放位置记忆，进度条用预生成的雪碧图做预览。

06

增量重建

按 CG 目录指纹判断，没变的库直接跳过；全部没变化时 0.6 秒返回。自检脚本一次查完裂图、缩略图、海报帧。

03

支持的引擎

Ren'Py.rpa/QLIEFilePackVer 3.0 · 3.1/Godot.pck/UnityAssetStudio

04

怎么用

STEP 01

装 Python 3.11+

安装时勾选 Add python.exe to PATH。还没打包成 exe，脚本会自己检查并提示。

STEP 02

拖进 一键处理.bat

识别引擎 → 解包 → 整理 → 建站 → 转视频抽海报 → 登记总收藏 → 打开浏览器。

STEP 03

双击 index.html

产物是 CG\index.html。之后加删图片，用 rebuild_all.py 增量重建。
