SakuraView

把 Galgame 的 CG 从各家引擎的打包文件里解出来，
生成零依赖、双击即看的静态图库。

纯 file:// 可用 无 Node / 无构建 单库十万张 示例素材全部程序合成
进入示例库 → GitHub 源码
目录页 · 分类色块 + 分组卡片 + 按组名搜索
分组页 · 横/竖/视频筛选 + 批量框选
视频页 · 倍速 / 循环 / 连播 / 雪碧图预览

它做什么

🔓

解包

Ren'Py 的 .rpa、QLIE 的 FilePackVer3.0/3.1、Godot 的 .pck 都能直接解，Unity 走 AssetStudio 导出纹理。

🗂️

整理

按目录名自动归类成「事件CG / 立绘 / 头像 / 动画」；一个都认不出时按「目录即分类」兜底，不会一张图都收不到。

🖼️

看图

灯箱 → 真全屏，滚轮/双指缩放、拖拽平移、R 旋转，每张图的缩放按图记忆，退出后自动滚回那一张。

⭐

收藏与备注

收藏倒序、行内备注（支持 **粗体** / #标签）、轻量标签、导出导入 JSON 备份。

🎬

视频

自制播放器：倍速、循环、连播、音量滑块、画中画、播放位置记忆，进度条用预生成的雪碧图做预览。

⚡

增量重建

按 CG 目录指纹判断，没变的库直接跳过；全部没变化时 0.6 秒返回。自检脚本一次查完裂图、缩略图、海报帧。

支持的引擎

Ren'Py.rpa
QLIEFilePackVer 3.0 / 3.1
Godot.pck
UnityAssetStudio 导出纹理

怎么用

① 装 Python 3.11+

安装时勾选 Add python.exe to PATH。还没打包成 exe，脚本会自己检查并提示。

② 把游戏文件夹拖到 一键处理.bat

识别引擎 → 解包 → 整理 → 建站 → 转视频/抽海报/生成缩略图 → 登记总收藏 → 打开浏览器，一条龙。

③ 等它跑完

产物是 CG\index.html，直接双击。之后往目录里加删图片，用 rebuild_all.py 增量重建。

示例库的每一张图都是 make_demo.py 用 Pillow 现画的，两段动画是 ffmpeg 现合成的， 不含任何商业游戏素材。

本工具不内置任何游戏密钥，也不分发第三方解包器。请仅对自己合法持有的游戏使用，提取出的素材请勿传播或商用。
